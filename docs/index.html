GitHub Fork Compare Fix —

Stop sending your fork’s pull requests upstream.

Use a fork as your own repository without fighting GitHub’s upstream defaults. Compare branches and open pull requests against the branch you actually use.

Download from GitHub Firefox Add-ons Chrome Web Store

What changes

See the branch relationship you care about. Ahead and behind counts are recalculated against your fork’s default branch.

Before

Counted against upstream, and every link here opens a pull request against upstream.

After

Counted against your own default branch, and the links stay in your repository.

Simple, per-repository setup

The fix is opt-in. Enable it for a single repository or use owner/* for an account, while forks used for upstream contributions remain unchanged.

Everything it fixes

All the usual compare links

It corrects the Contribute menu, branch banners, ahead links, and direct new-pull-request URLs.

Compare against your own base

Your fork’s default branch becomes the base, so the diff matches the work you intended to review.

Private by design

No sign-up and no data collection. Just local settings and the GitHub requests needed to fix the page.

You control the scope

Choose individual forks or an entire owner. The extension does nothing outside the scope you set.
